# Optional audio files

Drop MP3 files here and rebuild (`npm run build`); the game picks them up by name. Nothing here is required.

| File                      | When it plays                                              |
| ------------------------- | ---------------------------------------------------------- |
| `theme.mp3`               | Loops as background music (replaces the synthesised drone) |
| `narration-hermitage.mp3` | Opening story card                                         |
| `narration-forest.mp3`    | Agneyastra card                                            |
| `narration-night.mp3`     | Divya Drishti card                                         |
| `narration-temple.mp3`    | Temple and Vayavyastra cards                               |
| `narration-deer.mp3`      | Golden deer card                                           |
| `narration-vimana.mp3`    | Vimana card                                                |
| `narration-tataka.mp3`    | Tataka card                                                |
| `narration-rama.mp3`      | Ending card                                                |
